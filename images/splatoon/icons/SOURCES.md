# Splatoon ability icon stickers

The raster ability icons in this folder were redrawn by Reddit user
`u/ScaryGreenMountain` and shared for anyone to use without requiring creator
credit.

- Source post: https://www.reddit.com/r/splatoon/comments/1w6upnj/i_remade_all_of_the_splatoon_3_ability_icons_as/
- Original download: https://drive.google.com/file/d/1sqx3iTqttktAnUod6wei8ug1za_uSH46/view
- Retrieved: 2026-10-20
- Site copies: resized from the supplied 2000 px PNG files to 192 px WebP files
