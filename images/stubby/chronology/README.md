# Stubby chronology assets

These are public-ready copies of Ivy's private 2012-2025 photo archive. The source files remain outside the repository.

- Human faces are covered with the same opaque heart treatment.
- Visible text is blurred where needed.
- Still-image metadata is stripped during export.
- Included clips have no audio track.
- The shrine loads one featured image per year first; the remaining media loads only when a year is opened.
